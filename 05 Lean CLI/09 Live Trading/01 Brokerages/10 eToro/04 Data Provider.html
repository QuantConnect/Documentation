eToro provides a live data feed and serves historical data for the US Equities, Crypto, and Forex it supports. To use eToro as the live data provider, select it when you deploy. To use eToro as the historical data provider of local backtests, optimizations, and research, pass --data-provider-historical eToro to the lean backtest, lean optimize, or lean research commands. To download eToro data, run lean data download.

The eToro data provider serves quote data in minute, hour, and daily resolutions.

The eToro data provider serves raw data. To get adjusted Equity data in local deployments, download the US Equity Security Master.
