Follow these steps to run a local optimization job with data from Bloomberg DAPI through Quant Bridge:

  1. Add some parameters to your project.
  2. Open a terminal in your organization workspace.
  3. Run lean optimize <projectName> --data-provider-historical "Quant Bridge" --quant-bridge-connection-type DAPI --quant-bridge-environment <environment> --quant-bridge-server-host <serverHost> --quant-bridge-server-port <serverPort> --quant-bridge-emsx-broker <emsxBroker> --quant-bridge-openfigi-api-key <openfigiApiKey>.
    4. $ lean optimize "My Project" --data-provider-historical "Quant Bridge" --quant-bridge-connection-type DAPI --quant-bridge-environment Production --quant-bridge-server-host serverHost --quant-bridge-server-port serverPort --quant-bridge-emsx-broker emsxBroker --quant-bridge-openfigi-api-key openfigiApiKey
  4. Follow the steps in the interactive wizard to configure your optimization job settings.

The lean optimize command also accepts additional options so that you can select Quant Bridge and run the command in non-interactive mode. If you provide any of the preceding options, your Lean configuration file saves them so that you only need to run lean optimize <projectName> to run another optimization job with the same options.
