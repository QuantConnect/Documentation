The following table describes the keyboard shortcuts of the project list:

Keys Description
Up, Down, K, J Select the previous or next item.
Tab, Shift+Tab Move to the next or previous panel.
/ Move to the Filter panel.
Enter Move from the project list to the Actions panel, or run the selected action.
Esc Clear the filter and move to the project list.
B, C, V, P, U, S Run a project action.
R Refresh the project list.
X Stop the running command.
Q Close the UI.

The following table describes the keyboard shortcuts of the backtest results screen:

Keys Description
1, 2, 3 Show the Statistics, Orders, or Logs tab.
[, ] Show the next newer or older backtest.
O Pick a backtest from the list of local and cloud backtests.
R Reload the results.
X Stop the running backtest.
Esc Return to the project list.
