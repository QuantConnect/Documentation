The UI displays the following panels:

Panel Description
Filter Filters the project list. The list shows the projects whose name contains every word you enter, ignoring case.
Projects Lists the projects with their location, language, and name. Library projects appear in dim text.
Project Displays the name, location, language, cloud Id, local path, modification time, and description of the selected project.
Actions Lists the actions you can run on the selected project.
Output Displays the output of the command that the UI runs.

The header displays the path of the organization workspace and the footer displays the keyboard shortcuts of the current screen. The location column of the project list shows one of the following values:

Location Description
synced The project is in the organization workspace and in the cloud.
local The project is only in the organization workspace.
cloud The project is only in the cloud.

The UI matches local and cloud projects by the cloud Id in the project configuration. If you delete a cloud project, its local copy shows as local.
