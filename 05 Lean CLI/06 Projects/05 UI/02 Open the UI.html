Follow these steps to open the UI:

  1. Log in to the CLI if you haven't done so already.

    2. If you don't log in, the UI only lists your local projects and disables the actions that use the cloud.

  2. Open a terminal in the organization workspace.
  3. Run lean ui. 
    $ lean ui

The UI lists your local projects first and then loads your cloud projects. To refresh the project list, press R. On Linux, the CLI runs lean ui with sudo so the commands that the UI runs can access Docker.

To close the UI, press Q. If a command is running, the UI stops it before closing. The UI waits up to 10 seconds for the command to stop its Docker containers.
