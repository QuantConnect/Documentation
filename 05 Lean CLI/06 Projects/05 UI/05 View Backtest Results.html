To view the backtest results of a project, run the View backtest results action. The results screen opens the most recent backtest of the project and shows the following sections:

  • A summary of the equity, net profit, return, Probabilistic Sharpe Ratio (PSR), unrealized profit, holdings, fees, and volume.
  • The runtime error, if the algorithm throws an exception.
  • The Strategy Equity chart.
  • The Statistics, Orders, and Logs tabs.

The Orders tab shows the order time in UTC and loads more orders as you scroll down. While a backtest runs, the results screen refreshes every 10 seconds for local backtests and every 15 seconds for cloud backtests. To reload the results, press R.

The results screen lists the local backtests of the project and, if you're logged in, the cloud backtests of the project. To view another backtest, press [ for a newer backtest or ] for an older backtest. To pick a backtest from the full list, press O, enter a part of its name to filter the list, and then press Enter.

To return to the project list, press Esc. For more information about the backtest results, see Results.
