Follow these steps to run an action on a project:

  1. In the project list, select the project.
  2. Press Enter.
  3. In the Actions panel, select the action and then press Enter.

    4. To run an action without moving to the Actions panel, press the action key in the project list.

  4. If the UI asks you to confirm the command, press Y or Enter to run it.

    5. To cancel, press N or Esc. Backtest actions start without confirmation and open the backtest results.

The following table describes the actions:

Key Action Command Requirements
B Backtest locally lean backtest Local project
C Backtest in the cloud lean cloud backtest Logged in
V View backtest results Local backtests, or a cloud project and logged in
P Push to the cloud lean cloud push Local project and logged in
U Pull from the cloud lean cloud pull Cloud project and logged in
S Cloud live status lean cloud status Cloud project and logged in

If the selected project doesn't meet the requirements of an action, the Actions panel disables the action and shows the reason next to it. If you run a cloud backtest on a local project, the UI pushes the project to the cloud first.

The UI runs one command at a time and shows its output in the Output panel. After a push, a pull, or a cloud backtest, the UI refreshes the project list. Local backtests save their results in the backtests directory of the project.
