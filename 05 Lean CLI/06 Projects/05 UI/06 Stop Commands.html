To stop the running command, press X. The UI interrupts the command the same way Ctrl+C does, so the command can stop its Docker containers.

If the command doesn't stop, press X again to force the Docker containers to stop. Press X a third time to end the command process.

When you stop a cloud backtest, the UI asks whether to cancel and delete the backtest in the cloud. Press Y to delete it or N to keep the backtest running in the cloud.
