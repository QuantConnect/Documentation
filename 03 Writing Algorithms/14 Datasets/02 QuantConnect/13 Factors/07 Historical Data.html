To get historical factor data, call the Historyhistory method with the dataset Symbol. If there is no data in the period you request, the history result is empty.

# DataFrames
equity_factors_history_df = self.history(self._equity.factors, 100, Resolution.DAILY)
unlinked_factors_history_df = self.history(self._unlinked_factors, 100, Resolution.DAILY)

# Dataset objects
equity_factors_history = self.history[Factors](self._equity.factors, 100, Resolution.DAILY)
market_factors_history = self.history[Factors](self._unlinked_factors, 100, Resolution.DAILY)
var equityFactorsHistory = History<Factors>(_equityFactors, 100, Resolution.Daily);
var unlinkedFactorsHistory = History<Factors>(_marketFactors, 100, Resolution.Daily);

For more information about historical data, see History Requests.
