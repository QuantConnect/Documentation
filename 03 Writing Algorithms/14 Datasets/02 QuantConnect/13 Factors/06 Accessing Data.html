To get the current factor data, index the current Slice with the dataset Symbol. Slice objects deliver unique events to your algorithm as they happen, but the Slice may not contain data for your dataset at every time step. To avoid issues, check if the Slice contains the data you want before you index it. Each Factors object behaves like a dictionary, mapping the factor name to its value. Index the object with a factor name constant (for example, Factors.Technical.Roc1DayFactors.Technical.ROC_1_DAY is "technical_roc_1d") to get the value. 

def on_data(self, data: Slice) -> None:
    equity_factors = data.get(Factors).get(self._equity.factors)
    if equity_factors:
        value = equity_factors[Factors.ROC_1_DAY]

    unlinked_factors = data.get(Factors).get(self._unlinked_factors)
    if unlinked_factors:
        ust_yield = unlinked_factors[Factors.UST_YIELD_1_MONTH]
