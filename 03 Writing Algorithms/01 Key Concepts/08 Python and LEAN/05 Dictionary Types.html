Several LEAN objects work like Python dictionaries, such as self.portfolio, self.securities, slice.bars, slice.quote_bars, slice.option_chains, and slice.future_chains. To get their keys or values, call the keys() and values() methods with parentheses. To get the keys and values together, call the items() method.

# Iterate the values of the portfolio.
for holding in self.portfolio.values():
    self.log(f"{holding.symbol}: {holding.quantity}")

# Iterate the keys and values of the trade bars in the Slice.
for symbol, bar in slice.bars.items():
    self.log(f"{symbol}: {bar.close}")

If you omit the parentheses, the expression returns the method object instead of the collection, and the loop raises a 'MethodBinding' object is not iterable error.
