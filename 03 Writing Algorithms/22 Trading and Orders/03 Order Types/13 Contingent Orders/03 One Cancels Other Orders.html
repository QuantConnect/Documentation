To place a set of OCO orders, create an order request for each order with the order factory. Pass a list of the requests to the OneCancelsOtherOrderone_cancels_other_order method. All the orders start working right away. When one of them fills, even partially, LEAN cancels the rest of the set. The method returns a list with the order ticket of each order.

// Exit an existing long position at the first price level the market reaches.
var price = Securities[_symbol].Price;
var tickets = OneCancelsOtherOrder(new List<SubmitOrderRequest>
{
    OrderFactory.LimitOrder(_symbol, -100, price * 1.02m, tag: "Take profit"),
    OrderFactory.StopMarketOrder(_symbol, -100, price * 0.99m, tag: "Stop loss")
});
# Exit an existing long position at the first price level the market reaches.
price = self.securities[self._symbol].price
tickets = self.one_cancels_other_order([
    self.order_factory.limit_order(self._symbol, -100, price * 1.02, tag="Take profit"),
    self.order_factory.stop_market_order(self._symbol, -100, price * 0.99, tag="Stop loss")
])
