To place a set of OUO orders, create an order request for each order with the order factory. Pass a list of the requests to the OneUpdatesOtherOrderone_updates_other_order method. All the orders start working right away. When one of them partially fills, LEAN reduces the remaining quantity of the rest of the set by the same proportion. For example, if a take-profit order for -100 shares fills -40 shares, LEAN reduces the stop-loss order from -100 shares to -60 shares. When one of the orders completely fills, LEAN cancels the rest of the set. The method returns a list with the order ticket of each order.

var tickets = OneUpdatesOtherOrder(new List<SubmitOrderRequest>
{
    OrderFactory.LimitOrder(_symbol, -100, price * 1.02m, tag: "Take profit"),
    OrderFactory.StopMarketOrder(_symbol, -100, price * 0.99m, tag: "Stop loss")
});
tickets = self.one_updates_other_order([
    self.order_factory.limit_order(self._symbol, -100, price * 1.02, tag="Take profit"),
    self.order_factory.stop_market_order(self._symbol, -100, price * 0.99, tag="Stop loss")
])

LEAN rounds the new quantities to the lot size of the security. If a new quantity rounds to zero, LEAN cancels the order.
