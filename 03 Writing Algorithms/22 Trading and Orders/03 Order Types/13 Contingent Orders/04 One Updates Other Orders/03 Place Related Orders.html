Each order in an OUO set can trigger other orders. To trigger orders after an OUO order fills, call the Triggerstriggers method on its order request before you relate it with the other orders. The brokerage holds the triggered orders until their parent completely fills. If another order in the set completely fills, LEAN cancels the parent and the orders it triggers. This rule applies even if the parent partially filled.

// Reverse the long position when the stop loss fills.
var stopLoss = OrderFactory.StopMarketOrder(_symbol, -100, price * 0.99m).Triggers(OrderFactory.MarketOrder(_symbol, -100));
var tickets = OneUpdatesOtherOrder(new List<SubmitOrderRequest>
{
    OrderFactory.LimitOrder(_symbol, -100, price * 1.02m),
    stopLoss
});
# Reverse the long position when the stop loss fills.
stop_loss = self.order_factory.stop_market_order(self._symbol, -100, price * 0.99).triggers(
    self.order_factory.market_order(self._symbol, -100))
tickets = self.one_updates_other_order([
    self.order_factory.limit_order(self._symbol, -100, price * 1.02),
    stop_loss
])

The quantity of a triggered order doesn't change when LEAN reduces the quantity of its parent.
