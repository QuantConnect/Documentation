The exit orders that the BracketOrderbracket_order and Bracketbracket methods create can't trigger other orders. To make an exit trigger another order, build the bracket from its parts with the order factory. For more information, see Custom Contingent Orders.

  1. Call the Triggerstriggers method on the exit order request with the order to trigger.
  2. Relate the exit order requests with the OrderFactory.OneCancelsOtherorder_factory.one_cancels_other method.
  3. Pass the exit order requests to the Triggerstriggers method of the entry order request.
  4. Pass the entry order request to the Orderorder method.
// The take profit triggers a new entry at the entry price.
var takeProfit = OrderFactory.LimitOrder(_symbol, -100, price * 1.02m)
    .Triggers(OrderFactory.LimitOrder(_symbol, 100, price * 0.999m));
var stopLoss = OrderFactory.StopMarketOrder(_symbol, -100, price * 0.99m);
var entry = OrderFactory.LimitOrder(_symbol, 100, price * 0.999m)
    .Triggers(OrderFactory.OneCancelsOther(takeProfit, stopLoss));
var tickets = Order(entry);
# The take profit triggers a new entry at the entry price.
take_profit = self.order_factory.limit_order(self._symbol, -100, price * 1.02).triggers(
    self.order_factory.limit_order(self._symbol, 100, price * 0.999))
stop_loss = self.order_factory.stop_market_order(self._symbol, -100, price * 0.99)
entry = self.order_factory.limit_order(self._symbol, 100, price * 0.999).triggers(
    self.order_factory.one_cancels_other(take_profit, stop_loss))
tickets = self.order(entry)

The order that the exit triggers is a grandchild of the entry. The brokerage holds it until the exit completely fills. If the other exit fills first, LEAN cancels the exit and its grandchild. The Orderorder method returns the order tickets of the entry, the take profit, the order it triggers, and the stop loss, in that order.
