To place a set of OTO orders, create the parent and child order requests with the order factory and pass them to the OneTriggersOtherOrderone_triggers_other_order method. The brokerage holds the child orders until the parent order completely fills. If the parent order is canceled or invalid, LEAN cancels the child orders, even if the parent partially filled. The method returns a list with the order ticket of each order, starting with the parent.

// Buy IBM and BAC after the SPY entry fills.
var parent = OrderFactory.LimitOrder(_spy, 100, limitPrice);
var tickets = OneTriggersOtherOrder(parent, new List<SubmitOrderRequest>
{
    OrderFactory.MarketOrder(_ibm, 10),
    OrderFactory.MarketOrder(_bac, 20)
});
# Buy IBM and BAC after the SPY entry fills.
parent = self.order_factory.limit_order(self._spy, 100, limit_price)
tickets = self.one_triggers_other_order(parent, [
    self.order_factory.market_order(self._ibm, 10),
    self.order_factory.market_order(self._bac, 20)
])
