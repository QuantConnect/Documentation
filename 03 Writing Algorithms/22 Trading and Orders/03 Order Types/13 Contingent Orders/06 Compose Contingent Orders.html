The order factory creates SubmitOrderRequest objects without submitting them, so you can relate them before you place them. The order factory has a method for each order type, with the same arguments as the method that places the order. For example, OrderFactory.LimitOrderorder_factory.limit_order accepts the same arguments as LimitOrderlimit_order. To relate the order requests, use the following methods:

Method Description
request.Triggers(children)request.triggers(children) The request triggers the child orders when it completely fills (OTO).
request.Bracket(takeProfitPrice, stopLossPrice)request.bracket(take_profit_price, stop_loss_price) The request triggers a take-profit order and a stop-loss order that cancel each other.
OrderFactory.OneCancelsOther(requests)order_factory.one_cancels_other(requests) The first fill of a request cancels the others (OCO).
OrderFactory.OneUpdatesOther(requests)order_factory.one_updates_other(requests) A partial fill of a request reduces the quantity of the others (OUO).

The Triggerstriggers and Bracketbracket methods return the same request. The OneCancelsOtherone_cancels_other and OneUpdatesOtherone_updates_other methods return the list of requests. You can pass the result of one method to another to build any composition. To place the orders, pass any request of the set to the Orderorder method. The method places every order in the set and returns their order tickets, with each parent before the orders it triggers.

// A limit entry that triggers a take profit and a stop loss that cancel each other.
var entry = OrderFactory.LimitOrder(_symbol, 100, price * 0.999m);
var takeProfit = OrderFactory.LimitOrder(_symbol, -100, price * 1.02m);
var stopLoss = OrderFactory.StopMarketOrder(_symbol, -100, price * 0.99m);
entry.Triggers(OrderFactory.OneCancelsOther(takeProfit, stopLoss));
var tickets = Order(entry);
# A limit entry that triggers a take profit and a stop loss that cancel each other.
entry = self.order_factory.limit_order(self._symbol, 100, price * 0.999)
take_profit = self.order_factory.limit_order(self._symbol, -100, price * 1.02)
stop_loss = self.order_factory.stop_market_order(self._symbol, -100, price * 0.99)
entry.triggers(self.order_factory.one_cancels_other(take_profit, stop_loss))
tickets = self.order(entry)

You can submit each order request once. After you submit the request, its OrderIdorder_id property holds the order Id. To get the order ticket of a request, get it from the transaction manager.

var stopLossTicket = Transactions.GetOrderTicket(stopLoss.OrderId);
