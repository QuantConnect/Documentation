To relate the order requests, use the following methods:

Method Description Examples
request.Triggers(children)request.triggers(children) The request triggers the child orders when it completely fills (OTO). Place Related Orders
request.Bracket(takeProfitPrice, stopLossPrice)request.bracket(take_profit_price, stop_loss_price) The request triggers a take-profit order and a stop-loss order that cancel each other. Place Related Orders
OrderFactory.OneCancelsOther(requests)order_factory.one_cancels_other(requests) The first fill of a request cancels the others (OCO). Place Related Orders
OrderFactory.OneUpdatesOther(requests)order_factory.one_updates_other(requests) A partial fill of a request reduces the quantity of the others (OUO). Place Related Orders

The Triggerstriggers and Bracketbracket methods return the same request. The OneCancelsOtherone_cancels_other and OneUpdatesOtherone_updates_other methods return the list of requests. You can pass the result of one method to another to build any composition. To place the orders, pass any request of the set to the Orderorder method. The method places every order in the set and returns their order tickets, with each parent before the orders it triggers. You can add each order request to one OCO or OUO set.

// A limit entry that triggers a take profit and a stop loss that cancel each other.
var entry = OrderFactory.LimitOrder(_symbol, 100, price * 0.999m);
var takeProfit = OrderFactory.LimitOrder(_symbol, -100, price * 1.02m);
var stopLoss = OrderFactory.StopMarketOrder(_symbol, -100, price * 0.99m);
entry.Triggers(OrderFactory.OneCancelsOther(takeProfit, stopLoss));
var tickets = Order(entry);
