The combo methods of the order factory return a list with one order request for each leg. LEAN treats the legs of a combo order as a single member of the set. Pass all the legs whenever you relate or submit a combo order. When a combo order is the parent of an OTO set, LEAN triggers the child orders when all the legs completely fill. To use a combo order as the parent, pass the list of legs to the OneTriggersOtherOrderone_triggers_other_order method. The Bracketbracket method doesn't support combo orders.

// Buy a butterfly spread and sell it when its net price reaches the take-profit level.
var legs = new List<Leg>
{
    Leg.Create(calls[0].Symbol, 1),
    Leg.Create(calls[1].Symbol, -2),
    Leg.Create(calls[2].Symbol, 1)
};
var entry = OrderFactory.ComboMarketOrder(legs, 2);
var takeProfit = OrderFactory.ComboLimitOrder(legs, -2, takeProfitPrice);
var tickets = OneTriggersOtherOrder(entry, takeProfit);
