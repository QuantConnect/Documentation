To cancel a contingent order, call the Cancelcancel method on the OrderTicket. LEAN also cancels the orders that depend on it. If you cancel a parent order, LEAN cancels the orders it triggers and the orders they trigger in turn. If you cancel a member of an OCO or OUO set, LEAN cancels the rest of the set. This rule applies to working orders and to orders that wait for their parent to fill. The parent of the set keeps working.

// Cancel the entry of a bracket order, which also cancels the take profit and the stop loss.
var response = tickets[0].Cancel("Cancel bracket");
if (response.IsSuccess)
{
    Debug("Bracket order successfully cancelled");
}
# Cancel the entry of a bracket order, which also cancels the take profit and the stop loss.
response = tickets[0].cancel("Cancel bracket")
if response.is_success:
    self.debug("Bracket order successfully cancelled")

The message of the cancel order event of each dependent order names the order that caused the cancellation.
