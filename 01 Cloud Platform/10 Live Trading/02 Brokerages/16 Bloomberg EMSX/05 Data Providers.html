The Bloomberg™ Server API (SAPI) doesn't provide data, so we recommend the QuantConnect data provider, which is free and covers most of the asset classes that Bloomberg EMSX supports. It doesn't supply Index data, so add a third-party data provider such as Polygon to trade Index Options. Index Options need data for the underlying index, such as SPX, VIX, and NDX. For more information about live data providers, see Datasets.

This limitation applies to QuantConnect Cloud, which connects to the SAPI. Local deployments connect to the Bloomberg™ Desktop API (DAPI) instead, so Terminal Link can source live and historical data from your Bloomberg™ Terminal, within your Bloomberg™ license permissions. Intraday history goes back up to 6 months, and historical open interest and custom data aren't available. For more information, see Terminal Link.
