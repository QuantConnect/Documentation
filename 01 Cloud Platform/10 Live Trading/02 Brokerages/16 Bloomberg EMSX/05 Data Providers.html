The Bloomberg™ Server API (SAPI) does not provide data, you must use QuantConnect data provider, a third-party data provider such as a Polygon, or a broker that provides data.

This limitation applies to QuantConnect Cloud, which connects to the SAPI. Local deployments connect to the Bloomberg™ Desktop API (DAPI) instead, so Terminal Link can source live and historical data from your Bloomberg™ Terminal, within your Bloomberg™ license permissions. Intraday history goes back up to 6 months, and historical open interest and custom data aren't available. For more information, see Terminal Link.
