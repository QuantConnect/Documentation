eToro supports cash and margin accounts. To set the account type in an algorithm, see the eToro brokerage model documentation.

Create an Account

Follow the account creation wizard on the eToro website to create an eToro account. To access the eToro API, you must complete the eToro account verification.

Create API Credentials

To trade with the eToro API, you need your public API key and a user key. The following steps summarize how to create them. For the full process, see Authentication in the eToro API documentation.

  1. Log in to eToro.
  2. In the sidebar, click Settings > Trading.
  3. In the API Key Management section, copy the Public Key, which is your API key.
  4. Click Create Your API Key.
  5. In the Key Name field, enter a name for the key.
  6. In the Environment field, select Real to trade your real portfolio or Demo to trade your demo portfolio.
  7. In the Permissions field, select Write.
  8. Click Generate Key and then enter the verification code that eToro sends to your mobile device.
  9. Copy the user key that eToro displays.

The new key appears in the Generated Keys list, where you can edit or revoke it. Each user key works for one environment. To trade both environments, create one user key for each.

Paper Trading

eToro supports paper trading through its Demo environment. To paper trade, create a user key for the Demo environment and select the Demo environment when you deploy.
