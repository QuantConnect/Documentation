The Bloomberg™ FIX connection only routes orders, so it doesn't provide data. We recommend the QuantConnect data provider, which is free and supplies US Equities, US Equity Options, US Index Options, and Futures data during live trading. It doesn't supply Index data, so add a third-party data provider such as Polygon to trade Index Options. Index Options need data for the underlying index, such as SPX, VIX, and NDX. For more information about live data providers, see Datasets.
