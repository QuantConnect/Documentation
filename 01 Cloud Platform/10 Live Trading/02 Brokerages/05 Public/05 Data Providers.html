Public doesn't provide a live data feed, so we recommend the QuantConnect data provider, which is free and supplies US Equities, US Equity Options, US Index Options, and Crypto data during live trading. It supplies SPX and VIX Index data, which SPX and VIX Index Options need for the underlying index, but it doesn't supply other Index data, so add a third-party data provider such as Polygon to trade Index Options on other indices, such as NDX. For more information about live data providers, see Datasets.
