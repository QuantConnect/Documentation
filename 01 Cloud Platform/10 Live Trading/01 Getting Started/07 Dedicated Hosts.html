A dedicated host is a large server that we provision for your organization alone. It provides the equivalent of 80 cores and 160 GB of RAM, which we currently configure as 20 L4-8 live trading nodes, though other configurations are available on request. Dedicated hosts will only run the live deployments from your organization and are manually set up.

Dedicated hosts are available in the New York (NY7) and Toronto (TOR) regions. To request one, contact us.
