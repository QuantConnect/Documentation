You can choose the geographic region that hosts your live algorithm. Spreading your live algorithms across regions gives you better redundancy because an incident in one region doesn't affect the algorithms that run in the other regions.

The following table describes the available regions:

Region Code Location
America NY7 New York, United States
Canada TOR Toronto, Canada
Europe WAW Warsaw, Poland

America (NY7) is the default region. To use a different one, select it in the Region section of the Deploy Live page. The Node field then only lists the live trading nodes in your organization that are available in the region you select.
