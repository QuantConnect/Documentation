A live algorithm restarts when you stop it and deploy it again, when you update it, and when an automatic restart recovers it from a runtime error or an API disconnection. To restart an algorithm manually, stop it and then deploy it again.

To enable automatic restarts, select the Automatically restart algorithm check box when you deploy the algorithm. Automatic restarts use best efforts and stop after five failed attempts, so they don't replace monitoring your algorithm.

A restart doesn't save the state of the algorithm. Each restart starts a fresh instance that runs Initializeinitialize again, so the algorithm only recovers the cash, holdings, and, for some brokerages, the open orders of your account. It must rebuild everything else. To learn what a restart recovers and how to persist the rest with warm-up and the Object Store, see State Persistence.
