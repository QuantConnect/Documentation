If you experience issues trying to load the IDE, follow these steps:

  1. Check if you're using one of the supported browsers.
  2. Load the page without your browser cache.

    3. Press Ctrl+Shift+R (Cmd+Shift+R on macOS) to hard refresh the page. If the issue persists, open the page in a private (incognito) window. If the page works there, clear your browser cache.

  3. Enable cookies for quantconnect.com.

    4. The website needs its own cookies to keep you logged in. If your browser settings or an extension block them (for example, "I still don't care about cookies"), some pages, such as the Organization page, show the logged-out view even though the header shows you're logged in.

  4. Disable your browser add-ons.
  5. Test a different supported browser.
  6. Check your internet connection and speed.
  7. Disable your Virtual Private Network (VPN).
  8. Configure your network settings to use Google Public DNS.

    9. The DNS settings of some ISPs block Microsoft DNS, so some panels don't load and display the following message: "Server IP address could not be found".

    The following resources explain how to change your networks settings:

    • Firefox DNS-over-HTTPS
    • DNS Encryption with DNS over HTTPs (DoH) on Chrome
    • Microsoft Edge to have DNS over HTTPS (DoH) as the default DNS settings
    • Set up 1.1.1.1 - macOS
  9. Check your anti-virus settings.

    10. The internet protection of some anti-virus products block the "Service Workers" that the IDE needs to operate. Kaspersky and Avast are the two products that commonly block the IDE from using Service Workers. These are background threads that improve the IDE's experience.

  10. Check if your hard drive is full.
  11. Restart your computer and internet router.
  12. Try to load the IDE with a different computer, tablet, or cell phone.

If these steps don't solve the issues, send the logs to the Console Inspector to the Support Team.
