When the above processes and track record are insufficient, we offer ways to encrypt your code while working on the QuantConnect platform. Our encryption feature uses a locally hosted key to encrypt code at rest in our database with AES256 encryption. In case of a compromised database or rouge agent, your code would not be readable. For more information on this feature, see Project Encryption.

Unless your organization is on the Institution tier, Project Encryption is the only supported way to make your code unreadable. You may not obfuscate code yourself, such as with encoded, packed, or dynamically executed source code. Our security review must be able to read all code, because obfuscation can hide malicious code or data exports. The compilation and obfuscation step that runs before we deploy your code is a separate process that protects your strategy on our servers.
