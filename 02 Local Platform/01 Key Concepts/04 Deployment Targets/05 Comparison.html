Note the following differences between the Local Platform and Cloud Platform deployment targets. The Local Platform differences also apply when you run the Lean CLI on your own server or virtual private server (VPS).

Data

The Local Platform target uses your on-premises data. The Cloud Platform target has access to the data in the Dataset Market. Both targets enable you to import custom datasets.

The Cloud Platform target has the data on its servers, and the QuantConnect team keeps it up to date. With the Local Platform target, you license, download, and refresh the data yourself, even for live trading with a brokerage data provider. Live data providers such as Interactive Brokers serve raw prices. To trade US Equities with adjusted prices, download the US Equity Security Master. To trade continuous Futures contracts, download the US Futures Security Master.

Compute

The Local Platform target uses your on-premises hardware. The Cloud Platform target uses the QuantConnect Cloud compute. For more information about the backtesting, research, and live trading nodes in QuantConnect Cloud, see Resources.

Management

The Local Platform target is under the management of your on-premises team. The Cloud Platform target is under the management of the QuantConnect team.

Hardware Procurement

The Local Platform target uses your on-premises hardware, so it requires you to procure and management your own hardware. The Cloud Platform target uses the hardware in QuantConnect Cloud, so you don't need to procure or manage any of the hardware.

Engine Updates

The Cloud Platform target runs the latest version of LEAN and the brokerage integrations. The Local Platform target also uses the latest LEAN image by default, and the Lean CLI checks for a new image once a week. For more information, see Stay Up To Date. A running local live algorithm keeps the image it started with until you redeploy it. To pull the latest image when you deploy, pass the --update option to the lean live deploy command. If you run a custom LEAN build, you rebuild it yourself.

User Interface

The Cloud Platform target gives you the web IDE, the backtest results page, and the live results page, which you can open in any browser. The Local Platform target keeps the results on the computer that runs LEAN.

Live Operations

The Cloud Platform target provides the following live trading features that the Local Platform target doesn't have:

  • Automatic restarts after a runtime error or an API disconnection.
  • An email when your live algorithm stops because of a runtime error.
  • For Interactive Brokers, an email with a Connect button when you miss the weekly re-authentication, so you can reconnect before the market opens.

With the Local Platform target, you monitor the computer, Docker, and the algorithm yourself. The algorithm runs only while the computer runs.

Support

With the Cloud Platform target and a paid support seat, the Support Team can review the logs of your live deployments. They report any bug the logs expose to the engineering team. With the Local Platform target, the logs stay on your computer. Technical support for the Local Platform and the Lean CLI requires a Gold support seat. For more information, see Support Features.
