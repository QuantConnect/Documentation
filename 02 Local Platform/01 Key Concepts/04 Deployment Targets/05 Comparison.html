Note the following differences between the Local Platform and Cloud Platform deployment targets. The differences also apply when you run LEAN yourself on a server or a virtual private server (VPS) with the Lean CLI.

Data

The Local Platform target uses your on-premises data. The Cloud Platform target has access to the data in the Dataset Market. Both targets enable you to import custom datasets.

In QuantConnect Cloud, the data is already on the servers and the QuantConnect team keeps it up to date. In local deployments, you license, download, and refresh the data yourself, even for live trading with a brokerage data provider. Live data providers such as Interactive Brokers serve raw prices. To trade US Equities with adjusted prices, download the US Equity Security Master. To trade continuous Futures contracts, download the US Futures Security Master.

Compute

The Local Platform target uses your on-premises hardware. The Cloud Platform target uses the QuantConnect Cloud compute. For more information about the backtesting, research, and live trading nodes in QuantConnect Cloud, see Resources.

Management

The Local Platform target is under the management of your on-premises team. The Cloud Platform target is under the management of the QuantConnect team.

Hardware Procurement

The Local Platform target uses your on-premises hardware, so it requires you to procure and management your own hardware. The Cloud Platform target uses the hardware in QuantConnect Cloud, so you don't need to procure or manage any of the hardware.

Engine Updates

QuantConnect Cloud runs the latest version of LEAN and the brokerage integrations. In local deployments, you update the LEAN image yourself, and you rebuild any custom LEAN builds you run. For example, to pull the latest image when you deploy a live algorithm with the CLI, pass the --update option to the lean live deploy command.

User Interface

The Cloud Platform target gives you the web IDE, the backtest results page, and the live results page, which you can open in any browser. In local deployments, the results are on the computer that runs LEAN.

Live Operations

QuantConnect Cloud provides the following live trading features that local deployments don't have:

  • Automatic restarts after a runtime error or an API disconnection.
  • An email when your live algorithm stops because of a runtime error.
  • For Interactive Brokers, an email with a Connect button when you miss the weekly re-authentication, so you can reconnect before the market opens.

In local deployments, you monitor the computer, Docker, and the algorithm yourself. The algorithm runs only while the computer runs.

Support

In QuantConnect Cloud, the Support Team can review the logs of your deployments and report any bug they expose to the engineering team. In local deployments, the logs stay on your computer, so you share them with the Support Team yourself.
