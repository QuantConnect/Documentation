The following sections explain some issues you may encounter and how to resolve them.

Service Outages

The MCP server relies on the QuantConnect API and the client application. To check the status of the QuantConnect API, see our Status page. To check the status of your client and the LLM, see their status page.

Missing Agent Node

If your organization only has the free A-MICRO agent node, the MCP server returns the following error message:

The QuantConnect Remote MCP Server requires a dedicated Assistant node (A1-1, A4-8, or A16-32). Purchase nodes on the pricing page.

To resolve this issue, add a paid agent node to your organization.
