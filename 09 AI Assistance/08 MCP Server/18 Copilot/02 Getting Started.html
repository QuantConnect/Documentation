To connect Copilot in Local Platform to the QC MCP Server, follow these steps:

  1. In Local Platform, install the GitHub Copilot Chat extension.
  2. Press Ctrl+Shift+P to open the Command Palette, enter MCP: Open User Configuration, and then press Enter.
  3. Edit the mcp.json file that opens to include the following server configuration:
    4. {
  "servers": {
    "qc-mcp": {
      "url": "https://www.quantconnect.com/api/v2/mcp",
      "type": "http"
    }
  }
}
  4. Press Ctrl+S to save the mcp.json file.
  5. Click Allow.
  6. Open the authorization page in the browser that is logged into your QuantConnect account.
  7. In the Authorize MCP Server form, select the organization you want to connect to and then click Authorize.
  8. Create a new project or open an existing one.
  9. In the top navigation bar, click View > Chat.
  10. At the bottom of the Chat panel that opens, click Ask > Agent to switch to Agent mode.
