To connect Claude Code to the QC MCP Server, follow these steps:

  1. Open Claude Code.
  2. Click the menu icon in the top-left corner and then click File > Settings.
  3. On the Settings page, click Connectors.
  4. On the Connectors page, click Add.
  5. On the Add Custom Connector page, enter a name for the connector, enter the MCP server URL (https://www.quantconnect.com/api/v2/mcp), and then click Add.
  6. On the confirmation page, click Add.
  7. On the Connectors page, click Connect.

    8. It opens a page in your default browser. If you sign into your QuantConnect account with a different browser, update your computer's default browser application and then repeat these steps.

  8. In the browser page that opens, click Continue connecting.
  9. In the Authorize MCP Server form, select the organization you want to connect to and then click Authorize.

Claude Code should now show all the tools available through the QuantConnect MCP Server.

To connect Claude Code in Local Platform to the QC MCP Server, follow these steps:

  1. In Local Platform, install the Claude Code extension.
  2. Create a new project or open an existing one.
  3. In the top navigation bar, click the Claude Code icon.
  4. In the Claude Code panel, enter /mcp.

    5. It should show the the QuantConnect MCP Server is connected.
