To connect Codex to the QC MCP Server, follow these steps:

  1. Install and open the Codex app.
  2. Sign in with your ChatGPT account.
  3. In the left navigation bar, click the Customize icon.
  4. On the Plugins page, click Add > Add custom MCP server.
  5. In the Add custom MCP server form, enter a name for the server and enter the MCP server URL (https://www.quantconnect.com/api/v2/mcp).
  6. Select the I understand and want to continue and then click Create as a plugin.
  7. In the Connect QuantConnect window, click Connect QuantConnect.

    8. Codex opens a page in your default browser. If you sign into your QuantConnect account with a different browser, update your computer's default browser application and then repeat this step.

  8. In the Authorize MCP Server form, select the organization you want to connect to and then click Authorize.

To view the tools available through the QuantConnect MCP Server, enter /mcp in the Codex composer.
