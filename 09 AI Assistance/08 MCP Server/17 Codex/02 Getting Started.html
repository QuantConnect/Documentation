To connect Codex to the QC MCP Server, follow these steps:

  1. Install and open the Codex app.
  2. Sign in with your ChatGPT account.
  3. Press Ctrl+, on Windows or Cmd+, on macOS to open the Settings page.
  4. On the Settings page, click MCP servers.
  5. Click Add server.
  6. Enter a name for the server, select Streamable HTTP, enter the MCP server URL (https://www.quantconnect.com/api/v2/mcp), and then save the server.
  7. Click Restart.
  8. In the MCP servers list, click Authenticate.

    9. Codex opens a page in your default browser. If you sign into your QuantConnect account with a different browser, update your computer's default browser application and then repeat this step.

  9. In the Authorize MCP Server form, select the organization you want to connect to and then click Authorize.

To view the tools available through the QuantConnect MCP Server, enter /mcp in the Codex composer.
