To connect the Codex CLI to the QC MCP Server, follow these steps:

  1. Install the Codex CLI.
  2. In a terminal, add the QC MCP Server.
    3. codex mcp add quantconnect --url https://www.quantconnect.com/api/v2/mcp
  3. Log in to the QC MCP Server.
    4. codex mcp login quantconnect

    Codex opens a page in your default browser. If you sign into your QuantConnect account with a different browser, update your computer's default browser application and then repeat this step.

  4. In the Authorize MCP Server form, select the organization you want to connect to and then click Authorize.
  5. Start Codex.
    6. codex
  6. Enter /mcp.

    7. Codex lists the QuantConnect MCP Server and its tools.

To connect the Codex extension in Local Platform to the QC MCP Server, follow these steps:

  1. In Local Platform, install the Codex extension.
  2. Create a new project or open an existing one.
  3. In the primary side bar, click the Codex icon.
  4. If you already connected the Codex CLI to the QC MCP Server, skip the rest of these steps. The Codex extension uses the same MCP configuration as the Codex CLI.
  5. In the Codex panel, click the gear icon and then click MCP servers.
  6. Click Add server.
  7. Enter a name for the server, select Streamable HTTP, enter the MCP server URL (https://www.quantconnect.com/api/v2/mcp), and then save the server.
  8. Click Restart extension.
  9. In the MCP servers list, click Authenticate.
  10. In the Authorize MCP Server form, select the organization you want to connect to and then click Authorize.
