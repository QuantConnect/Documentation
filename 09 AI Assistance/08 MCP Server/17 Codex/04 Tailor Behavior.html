The AGENTS.md file is a special file that tailors how Codex behaves during your conversations. Before Codex starts working, it reads the AGENTS.md file in your home directory (~ / .codex /). It also reads each AGENTS.md file from the root of your project down to the folder you open in Codex. The files closer to that folder take precedence. To tailor Codex for your QuantConnect workflow, use the same instructions as the example CLAUDE.md file. The file has no strict format.

For more information about AGENTS.md files, see Custom instructions with AGENTS.md in the Codex documentation.
