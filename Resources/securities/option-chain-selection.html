Select Contracts

To get a single contract from the chain, call the Selectselect method. It returns the contract that best matches the criteria you provide, or nullNone when the chain holds no match. 

// Get the put contract at 85% of the underlying price, from the expiration closest to 30 days out.
var contract = chain.Select(OptionRight.Put, targetDte: 30, moneyness: -0.15m);
# Get the put contract at 85% of the underlying price, from the expiration closest to 30 days out.
contract = chain.select(OptionRight.PUT, target_dte=30, moneyness=-0.15)

These methods take a target number of days to expiration and return the closest expiration within the optional minDtemin_dte and maxDtemax_dte window. The Option strategy filters instead take a minimum number of days to expiration and return the first expiration at or after it.

The following table describes the contract selection methods of the OptionChain class:

Select(OptionRight? right, int? targetDte, int? minDte, int? maxDte, decimal moneyness)select(right: OptionRight = None, target_dte: int = None, min_dte: int = None, max_dte: int = None, moneyness: float = 0)

Selects the contract with the strike closest to moneynessmoneyness as a signed fraction of the underlying price. For example, -0.15 targets 85% of the underlying price and 0 targets the at-the-money strike.
Pick(OptionRight? right, int? targetDte, int? minDte, int? maxDte, decimal moneyness)pick(right: OptionRight = None, target_dte: int = None, min_dte: int = None, max_dte: int = None, moneyness: float = 0)

A synonym of the Selectselect method.
SelectByStrikeDistance(decimal strikeFromAtm, OptionRight? right, int? targetDte, int? minDte, int? maxDte)select_by_strike_distance(strike_from_atm: float, right: OptionRight = None, target_dte: int = None, min_dte: int = None, max_dte: int = None)

Selects the contract with the strike closest to a signed distance from the underlying price, in price units. This is how the Option strategy filters express their strikes.
SelectByDelta(decimal targetDelta, OptionRight? right, int? targetDte, int? minDte, int? maxDte)select_by_delta(target_delta: float, right: OptionRight = None, target_dte: int = None, min_dte: int = None, max_dte: int = None)

Selects the contract with the absolute delta closest to the absolute target, so a 30 delta put is 0.3 or -0.3. Contracts without Greeks are ignored.
AtTheMoney(OptionRight? right)at_the_money(right: OptionRight = None)

Selects the contract with the strike closest to the underlying price. Ties go to the lower strike, then to the nearest expiration.
ClosestExpiry(int? targetDte, int? minDte, int? maxDte)closest_expiry(target_dte: int = None, min_dte: int = None, max_dte: int = None)

Returns the expiration date closest to the target number of days out, or nullNone when no expiration falls in the window.
At(DateTime expiry)at(expiry: datetime)

Returns a new chain with the contracts of the given expiration date. The time of day is ignored.

The expiration methods compose with the chain filters, so you can narrow a single expiration down further. 

var expiry = chain.ClosestExpiry(targetDte: 45, minDte: 30, maxDte: 60);
var contracts = chain.At(expiry.Value).PutsOnly().Strikes(-2, 0);
expiry = chain.closest_expiry(target_dte=45, min_dte=30, max_dte=60)
contracts = chain.at(expiry).puts_only().strikes(-2, 0)

OptionChain objects also expose read-only views of their contracts: Callscalls and Putsputs, sorted by expiration and then strike; Expiriesexpiries, the distinct expiration dates in ascending order; and StrikePricesstrike_prices, the distinct strikes in ascending order.

StrikePricesstrike_prices is a StrikeList object, which adds the ClosestToclosest_to, FirstAbovefirst_above, and FirstBelowfirst_below methods. Each one takes a reference price and returns nullNone when no strike matches. 

var strike = chain.StrikePrices.FirstAbove(chain.Underlying.Price);
strike = chain.strike_prices.first_above(chain.underlying.price)
