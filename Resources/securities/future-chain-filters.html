Filter Chains

FuturesChain objects provide the same filter methods as Futures universe selection, with the same names and the same behavior. Each method returns a new FuturesChain and leaves the source chain unchanged, so you can chain the calls together. 

// Select the front contract that expires at least 90 days out.
var contract = chain.ExpiringAfter(Time.AddDays(90)).FrontMonth().FirstOrDefault();

// Select the quarterly contracts.
var quarterlies = chain.ContractMonths(FutureExpirationCycles.March);
# Select the front contract that expires at least 90 days out.
contract = next(iter(chain.expiring_after(self.time + timedelta(days=90)).front_month()), None)

# Select the quarterly contracts.
quarterlies = chain.contract_months(FutureExpirationCycles.MARCH)

To filter the chain with your own predicate, use LINQ's Where method.

To filter the chain with your own predicate, call the where method.

var liquidContracts = chain.OpenInterest(100000, long.MaxValue).Where(contract => contract.Volume > 0);
liquid_contracts = chain.open_interest(100000, sys.maxsize).where(lambda contract: contract.volume > 0)

The StandardsOnlystandards_only and WeeklysOnlyweeklys_only methods of a chain apply to the contracts the chain already holds, so you can combine them with the expiration filters in any order. In universe selection, these two filters always run last.
