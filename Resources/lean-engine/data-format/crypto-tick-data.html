Tick files have trade ticks and quote ticks. The following table describes the columns of trade ticks:

Column Description
Time Milliseconds since midnight
Price Trade price
Quantity Quantity traded
Suspicious 1 if the tick is suspicious and 0 otherwise

The following table describes the columns of quote ticks:

Column Description
Time Milliseconds since midnight
Bid Price Best bid price
Bid Size Size of the best bid
Ask Price Best ask price
Ask Size Size of the best ask
Suspicious 1 if the tick is suspicious and 0 otherwise

LEAN also reads tick files that don't have the Suspicious column.
