The maximum number of files and the maximum file size you can have in a project depend on your organization's tier. The following table shows the quotas of each tier:

Tier Max Files per Project Max File Size (KB)
Free 25 32
Quant Researcher 50 64
Team 75 128
Trading Firm 100 256
Institution 250 256

If a project needs more files than its quota allows, move part of the code into a library. Each library is a project, so it has its own file quota. Read the library best practices first, because editing a library affects every project that uses it.
