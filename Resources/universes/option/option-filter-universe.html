The same filter methods are available on OptionChain objects, so you can reuse them to narrow down a chain you receive during the algorithm.

The following table describes the filter methods of the OptionFilterUniverse class:

Strikes(int minStrike, int maxStrike)strikes(min_strike: int, max_strike: int)

Selects contracts that are within minStrikem_strike strikes below the underlying price and maxStrikemax_strike strikes above the underlying price.
Strikes(IEnumerable<decimal> strikes)strikes(strikes: list[float])

Selects the contracts with any of the given strike prices.
StrikesAbove(decimal price)strikes_above(price: float)

Selects the contracts with strike prices above the given price. The price itself is excluded.
StrikesBelow(decimal price)strikes_below(price: float)

Selects the contracts with strike prices below the given price. The price itself is excluded.
OutOfTheMoney()out_of_the_money()
OTM()otm()

Selects the out-of-the-money contracts: calls with strikes above the underlying price and puts with strikes below it. Selects nothing when the underlying price is unknown.
InTheMoney()in_the_money()
ITM()itm()

Selects the in-the-money contracts: calls with strikes below the underlying price and puts with strikes above it. Selects nothing when the underlying price is unknown.
AtTheMoney(decimal? maxStrikeDistance = null)at_the_money(max_strike_distance: float = None)
ATM(decimal? maxStrikeDistance = null)atm(max_strike_distance: float = None)

Selects the at-the-money contracts. By default, it selects the strikes on either side of the underlying price, each only when it is within OptionFilterUniverse.DefaultAtTheMoneyStrikeDistanceOptionFilterUniverse.default_at_the_money_strike_distance (2%) of the price. With maxStrikeDistancemax_strike_distance, it selects every strike within that distance of the price, in price units. Selects nothing when the underlying price is unknown.
CallsOnly()calls_only()

Selects call contracts.
PutsOnly()puts_only()

Selects put contracts.
StandardsOnly()standards_only()

Selects standard contracts.
WeeklysOnly()weeklys_only()

Selects weekly contracts.
FrontMonth()front_month()

Selects the front month contract.
BackMonths()back_months()

Selects the non-front month contracts.
BackMonth()back_month()

Selects the back month contracts.
FarthestExpiration()farthest_expiration()

Selects the contracts with the farthest expiration date.
Expiration(int minExpiryDays, int maxExpiryDays)expiration(min_expiryDays: int, max_expiryDays: int)

Selects contracts that expire within a range of dates relative to the current day.
Expiration(IEnumerable<DateTime> expiries)expiration(expiries: list[datetime])

Selects the contracts that expire on any of the given dates. The time of day is ignored.
ExpiringAfter(DateTime date)expiring_after(date: datetime)

Selects the contracts that expire after the given date. The date itself is excluded and the time of day is ignored.
ExpiringBefore(DateTime date)expiring_before(date: datetime)

Selects the contracts that expire before the given date. The date itself is excluded and the time of day is ignored.
ZeroDte()zero_dte()

Selects the contracts that expire today.
Contracts(IEnumerable<Symbol> contracts)contracts(contracts: list[Symbol])

Selects a list of contracts.
Contracts(Func<IEnumerable<Symbol>, IEnumerable< Symbol>> contractSelector)contracts(contract_selector: Callable[[list[Symbol]], list[Symbol]])

Selects contracts that a selector function selects.

The preceding methods return an OptionFilterUniverse, so you can chain the methods together.
