Your organization's Object Store includes a reserved .agent folder that the QuantConnect AI agents read. It holds the custom skills and templates you define for your organization, which let the agents apply your own expertise and start new projects from your own scaffolds. The agents save each project's memory in the .assistant / memories / <project_id> / memory.md file.

The .agent folder contains the following subfolders:

SubfolderPurpose
skills Reusable instructions and conventions the agents apply.
templates Your own project scaffolds for the agents to initialize for new projects.
