Your organization's Object Store includes a reserved .assistant folder that the QuantConnect AI agents read. It holds the custom skills, memories, and templates that let the agents apply your own expertise, remember each project's context, and start new projects from your own scaffolds.

The .assistant folder contains the following subfolders:

SubfolderPurpose
skills Reusable instructions and conventions the agents apply.
memories Facts the agents remember about each project, in one <project_id> / memory.md file per project.
templates Your own project scaffolds for the agents to initialize for new projects.
