The following table shows the paths of the Index data files:

Resolution Zip File CSV File
Second and minute index / <market> / <resolution> / <ticker> / <date>_trade.zip <date>_<ticker>_<resolution>_trade.csv
Hour and daily index / <market> / <resolution> / <ticker>.zip <ticker>.csv

Each zip file contains one CSV file. For example, index / usa / minute / spx / 20210104_trade.zip contains 20210104_spx_minute_trade.csv.
