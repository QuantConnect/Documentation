The following table shows the paths of the US Equity data files:

Resolution Zip File CSV File
Tick equity / usa / tick / <ticker> / <date>_<tickType>.zip <date>_<ticker>_Trade_Tick.csv
<date>_<ticker>_Quote_Tick.csv
Second and minute equity / usa / <resolution> / <ticker> / <date>_<tickType>.zip <date>_<ticker>_<resolution>_<tickType>.csv
Hour and daily equity / usa / <resolution> / <ticker>.zip <ticker>.csv

Each zip file contains one CSV file. For example, equity / usa / minute / aapl / 20140605_trade.zip contains 20140605_aapl_minute_trade.csv. The CSV file names of tick data capitalize the tick type and resolution.
