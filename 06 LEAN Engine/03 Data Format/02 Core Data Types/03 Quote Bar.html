A QuoteBar row aggregates the bid and ask quotes of one period. The following table describes the columns, with an example row from 20131006_es_minute_quote_201312.csv in future / cme / minute / es / 20131006_quote.zip:

Column Description Example
Time Start time of the bar 68400000
Bid Open Opening bid price 1681.5
Bid High Highest bid price 1681.5
Bid Low Lowest bid price 1681.5
Bid Close Closing bid price 1681.5
Bid Size Size of the last bid in the period 5
Ask Open Opening ask price 1682
Ask High Highest ask price 1682
Ask Low Lowest ask price 1682
Ask Close Closing ask price 1682
Ask Size Size of the last ask in the period 19

If a period has no bid quotes, the four bid price columns are empty and the bid size is 0. The same rule applies to the ask side. For example, the following row from the same file has no bid quotes: 

75660000,,,,,0,1682.25,1682.25,1682.25,1682.25,39
