A Tick row records one trade, one quote update, or one open interest update. Tick data has no period. The following table shows the TickType of the rows in each tick file:

File Tick Type TickType Row Content
trade TradeTRADE One trade
quote QuoteQUOTE One update of the best bid or ask
openinterest OpenInterestOPEN_INTEREST One open interest update
