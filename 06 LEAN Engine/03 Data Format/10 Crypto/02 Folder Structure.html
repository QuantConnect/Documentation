The following table shows the paths of the Crypto data files:

Resolution Zip File CSV File
Tick, second, and minute crypto / <market> / <resolution> / <ticker> / <date>_<tickType>.zip <date>_<ticker>_<resolution>_<tickType>.csv
Hour and daily crypto / <market> / <resolution> / <ticker>_<tickType>.zip <ticker>.csv

Each zip file contains one CSV file. For example, crypto / coinbase / minute / btceur / 20180404_trade.zip contains 20180404_btceur_minute_trade.csv. The hour and daily zip file names include the tick type, but the CSV file names don't. For example, crypto / coinbase / daily / btcusd_trade.zip contains btcusd.csv.
