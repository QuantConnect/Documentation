The following table shows the paths of the Forex and CFD data files:

Resolution Zip File CSV File
Tick, second, and minute <securityType> / <market> / <resolution> / <ticker> / <date>_quote.zip <date>_<ticker>_<resolution>_quote.csv
Hour and daily <securityType> / <market> / <resolution> / <ticker>.zip <ticker>.csv

In these paths, <securityType> is forex or cfd. Each zip file contains one CSV file. For example, forex / oanda / minute / eurusd / 20140501_quote.zip contains 20140501_eurusd_minute_quote.csv.
