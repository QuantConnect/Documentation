The following table shows the paths of the Crypto Futures data files:

Resolution Zip File CSV File
Tick, second, and minute cryptofuture / <market> / <resolution> / <ticker> / <date>_<tickType>.zip <date>_<ticker>_<resolution>_<tickType>_perp.csv
Hour and daily cryptofuture / <market> / <resolution> / <ticker>_<tickType>.zip <ticker>_<tickType>_perp.csv

The perp suffix marks a perpetual contract. For a contract with an expiry date, LEAN uses <contractMonth> as the suffix. For example, cryptofuture / binance / minute / adausdt / 20221213_trade.zip contains 20221213_adausdt_minute_trade_perp.csv.
