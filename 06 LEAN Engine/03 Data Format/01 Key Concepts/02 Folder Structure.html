LEAN organizes data files into folders by security type, market, and resolution. The following table shows the security type folder of each asset class:

Asset Class Folder
US Equity equity
Equity Options option
Index index
Index Options indexoption
Futures future
Future Options futureoption
Forex forex
CFD cfd
Crypto crypto
Crypto Futures cryptofuture

The market folder separates assets that have the same ticker but trade on different exchanges or brokerages. For example, BTCUSDT trades on several exchanges at slightly different prices, so each exchange has its own folder under crypto.

In general, tick, second, and minute data have one zip file for each ticker and day, in a ticker folder. Hour and daily data have one zip file for many days, in the resolution folder. The following list shows the general path patterns:

  • Tick, second, and minute: <securityType> / <market> / <resolution> / <ticker> / <date>_<tickType>.zip
  • Hour and daily: <securityType> / <market> / <resolution> / <ticker>.zip

Options, Futures, and Crypto add more fields to these paths, and some zip files hold one CSV file for each contract. Each asset class page gives the exact paths. The following table describes the placeholders in the paths:

Placeholder Value
<securityType> Security type folder from the first table
<market> Lowercase market name, such as usa, cme, oanda, or coinbase
<resolution> tick, second, minute, hour, or daily
<ticker> Lowercase ticker
<tickType> trade, quote, or openinterest
<date> Date of the data in YYYYMMDD format
<year> Year of the data in YYYY format
<style> Option style: american or european
<right> Option right: call or put
<strike> Option strike price multiplied by 10,000
<expiry> Option expiry date in YYYYMMDD format
<contractMonth> Futures contract month in YYYYMM format
