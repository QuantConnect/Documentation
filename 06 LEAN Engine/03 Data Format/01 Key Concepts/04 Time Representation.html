The first column of every row is the time. In tick, second, and minute files, the time is the number of milliseconds since midnight of the file date. Tick times can have a fractional part, such as 43.142. In hour and daily files, the time has the YYYYMMDD HH:mm format, such as 20140606 00:00. The time of a bar is the start of its period.

The times are in the data time zone of the security, which can differ from its exchange time zone. To find the data time zone, look up the dataTimeZone value of the security in the market-hours / market-hours-database.json file. The keys of this file combine the security type, market, and ticker, such as Equity-usa-[*]. The [*] ticker applies to every ticker that has no entry of its own.

LEAN converts the times to the exchange time zone when it reads the files. For more information about time zones, see Data Time Zone.
